## Código

- Monorepo npm workspaces (`apps/*`, `packages/*`)
- Features da API devem incluir testes (`npm test` em `kunk-api`)
- Frontends: siga padrões do app alvo e pacotes compartilhados
- Não commitar secrets (`.env`, chaves)

## Documentação

- Fonte técnica canônica: `project-tools/docs/`
- A documentação pública do produto é gerada a partir dessa fonte e das páginas de introdução, instalação e operação

## Pull requests

Descreva o “porquê”, inclua plano de teste e mantenha o escopo focado.
