O Kunk reúne quatro aplicações para os diferentes papéis da associação e uma API central. Escolha um sistema para conhecer seus fluxos, recursos e documentação técnica.

| Sistema | Papel e recursos | Documentação |
|---|---|
| Cadastro de Associados | Adesão, documentos, dados clínicos, termos e acompanhamento do associado. | [Abrir](/frontend/cadastramento/) |
| Assinatura de termos | Criação e assinatura de termos e documentos com trilha auditável. | [Abrir](/frontend/doc-sign/) |
| Kunk | Acolhimento, triagem, serviços, pedidos, pagamentos e relatórios da operação. | [Abrir](/frontend/kunk/) |
| Área Admin | Serviços, profissionais, usuários, permissões, configurações e integrações da instância. | [Abrir](/frontend/admin/) |
| API | Autenticação, dados, regras de negócio, arquivos e integrações compartilhadas. | [Abrir](/api/) |
