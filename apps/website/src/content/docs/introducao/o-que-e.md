---
title: O que é o Kunk
description: Visão geral do produto open source para associações de cannabis medicinal.
---

O **Kunk** é um sistema open source de gestão associativa para cannabis medicinal.

Aplicações especializadas atendem os diferentes papéis da associação e compartilham uma API central.

| Sistema | Público e função |
|---|---|
| Cadastro de Associados | Associados: adesão, documentos, dados clínicos, termos e acompanhamento. |
| Assinatura de termos | Associados e operadores: termos e documentos com assinaturas auditáveis. |
| Kunk | Operadores (`system_users`): acolhimento, triagem, serviços, pedidos e relatórios. |
| Área Admin | Administradores: configuração, cadastros operacionais, usuários e integrações. |
| API | Todos os sistemas: autenticação, dados, regras de negócio, arquivos e integrações. |

Instalação previsível, PostgreSQL nativo e termos digitais no mesmo produto.
