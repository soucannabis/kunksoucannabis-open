| Caminho | Função |
|---|---|
| `apps/registration/` | Cadastro de Associados |
| `apps/doc-sign/` | Assinatura de termos e documentos |
| `apps/kunk/` | Painel operacional |
| `apps/admin/` | Área Admin da instância |
| `kunk-api/` | API REST nativa (PostgreSQL) |
| `packages/` | UI, tema, auth, forms, api-client, etc. |
| `project-tools/docs/` | Fonte da documentação técnica sincronizada |
| `project-tools/roadmap/` | Roadmap / checklist interno |
| `docker-compose.kunk.yml` | Stack local unificado (API + apps) |
