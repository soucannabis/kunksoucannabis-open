## Para que serve

Área para **consultar e editar registros** do sistema (associados, tags, produtos, etc.), organizados por tipo (coleções).

## O que você configura / faz

- Listar, filtrar e abrir registros
- Criar ou editar itens quando necessário
- Acompanhar dados operacionais sem ir ao banco de dados

## Quando usar

Para auditoria pontual, correção de cadastro e edição de dados diretamente no banco de dados.
