## Para que serve

Liga ou desliga o **cache da API** e permite **limpar** o cache quando algo parece desatualizado.

## O que você configura

- Ativar / desativar cache operacional
- Botão para limpar cache

## Quando usar

Se alterações recentes não aparecem imediatamente, limpe o cache. Em geral, deixe o cache ligado em produção para melhor desempenho.
