## Para que serve

Exibe **métricas de desempenho** das páginas (Core Web Vitals): velocidade e estabilidade visual percebidas pelos usuários.

## O que você faz

- Consultar indicadores agregados
- Identificar páginas lentas ou instáveis

## Quando usar

Para monitorar a qualidade da experiência nos apps (cadastro, Kunk, etc.), em especial após mudanças grandes de interface.
