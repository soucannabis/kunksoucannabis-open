## Para que serve

Gerencia as **contas de operadores** que entram no Admin e no Kunk: convidar, editar e definir perfis.

## O que você configura

- Lista de usuários do sistema
- Convite de novos operadores
- Dados e papéis de cada conta

## Quando usar

Ao admitir alguém da equipe ou revogar acesso. Somente perfis com papel **Administrador** acessam este Admin.
