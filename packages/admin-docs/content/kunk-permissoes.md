## Para que serve

Define **quais páginas do menu do Kunk** cada perfil (role) pode ver — por exemplo, recepção, farmácia, administração.

## O que você configura

- Páginas liberadas por perfil
- O que cada tipo de operador enxerga no dia a dia

## Quando usar

Ao criar novos perfis ou restringir áreas sensíveis do painel operacional.
