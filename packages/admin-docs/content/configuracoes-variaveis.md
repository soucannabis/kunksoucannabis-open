## Para que serve

Lista as **variáveis de configuração** agrupadas por sistema (cadastro, loja, serviços, etc.). São ajustes finos que controlam comportamento interno.

## O que você configura

- Valores por sistema (textos, flags, números)
- Itens sensíveis aparecem mascarados após salvar

## Quando usar

Quando a documentação de um módulo ou o suporte indicar uma variável específica. Prefira as telas dedicadas (triagem, aparência, serviços externos) quando existirem — elas são mais claras.
