## Para que serve

Melhora a **validação de endereços** (geocoding). O ViaCEP (Correios) funciona sem chave; o Geoapify completa a verificação quando ativado.

## Credenciais

Uma **API Key** no painel Geoapify.

### Passo a passo

1. Crie conta em [geoapify.com](https://www.geoapify.com).
2. Em [myprojects.geoapify.com](https://myprojects.geoapify.com) → **API Keys**, crie ou copie a chave.
3. Cole no Admin → **Autenticar**.
4. Ative o **módulo** e marque **Usar na verificação de endereço**.
