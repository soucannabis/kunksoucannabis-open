## Para que serve

Integra **Utalk / Umbler Talk** para WhatsApp: mapear atendentes e, opcionalmente, mensagem automática na triagem.

## Credenciais

**Organization ID** e **API Token** (Bearer) do painel Utalk.

### Passo a passo

1. Acesse [app.utalk.chat](https://app.utalk.chat/) com a conta da organização.
2. Em configurações / API, copie Organization ID e gere ou copie o API Token.
3. Cole no Admin (e a URL base se pedirem) → **Autenticar**.
4. Ative o módulo.
5. Cadastre o **utalk_id** de cada operador no mapeamento de atendentes.
6. Opcionalmente configure a mensagem automática da triagem.
