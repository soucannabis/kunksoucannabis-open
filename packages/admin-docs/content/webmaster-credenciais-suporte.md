## Para que serve

Gera uma conta de **Administrador** para o time de suporte da SouCannabis acessar a instalação com privilégios totais.

## O que você configura

- Criação do usuário (e-mail padrão `webmaster@soucannabis.ong.br`)
- Senha gerada automaticamente (exibida **uma única vez** após criar)
- Remoção do usuário de suporte

## Quando usar

Quando a associação precisar liberar acesso temporário ao suporte. Após copiar e-mail e senha, feche o modal — a senha não volta a ser mostrada. Para renovar o acesso, remova o usuário e crie outro.
