## Para que serve

Define os **textos de boas-vindas e de cadastro concluído** do app de cadastramento de associados, e se a tela final oferece um atalho para abrir uma solicitação de contato (triagem).

## O que você configura

- **Texto de boas-vindas** — exibido na tela `/bem-vindo`
- **Texto de cadastro concluído** — exibido em `/cadastro-concluido` após o associado finalizar o cadastro
- **Exibir botão da triagem** — mostra ou oculta o botão “Abrir uma solicitação de contato” na tela de concluído
- **URL do formulário de contato** — destino do botão (padrão `/contato`), quando o botão está habilitado

Use **Restaurar padrão** para voltar aos textos e opções padrão do sistema.

## Quando usar

Quando a associação quiser mudar a mensagem de boas-vindas ou de conclusão, ou ligar/desligar o atalho para a triagem após o cadastro.
