## Para que serve

Mostra **falhas registradas pelo sistema** (agrupadas) para a equipe técnica ou o administrador investigar.

## O que você faz

- Ver grupos de erros recentes
- Abrir detalhes para entender a causa
- Acompanhar se um problema voltou a ocorrer

## Quando usar

Quando algo “não funciona” e você precisa de pistas concretas (mensagem, frequência, contexto).
