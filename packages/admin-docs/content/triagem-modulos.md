## Para que serve

Liga ou desliga **recursos opcionais** da triagem — por exemplo, uso de documentos ou dados do associado no fluxo.

## O que você configura

- Flags de módulos (ativar / desativar)
- Comportamentos extras ligados à fila

## Quando usar

Quando a associação quiser enriquecer a triagem com dados já cadastrados do associado, ou simplificar o fluxo.
